Appendix A

Decision & Estimation Logic

Project Analysis (Pillar 2)
  • 10 axes, 1–5 scale with AI assist
  • Verdict: Proceed / Conditional / Do Not Proceed
  • Score ≤ 2 → auto-generated risk register
Personnel Analysis (Pillar 1)
  • Feature extraction from GitHub + Slack signals
  • LLM → 5-layer profile with confidence score
  • Cosine similarity → developer ↔ project match
WFU_effective 
WFU = base
    × familiarity_factor
    × tech_match_factor
    × quality_history_factor
    × delivery_reliability_factor
P(on_time)

SPI · velocity variance · warnings · critical path slack. Below 40% for 3 days → RISK_ESCALATION.
