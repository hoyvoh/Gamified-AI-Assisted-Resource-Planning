# FE-013 — Calendar View

**Phase:** 5 — Views & Visualizations
**Track:** Frontend
**Branch:** `feature/FE-013-calendar-view`
**Status:** Not started
**Prerequisites:** INT-001

## Goal
Monthly calendar grid showing who is working on what each day. Colored dots per person per day, milestone markers, and day-click popover with task details.

## Scope
- Monthly grid (prev/next month navigation)
- Each day cell: colored dots per assigned person
- Milestone markers for critical task planned_end dates
- Click day → popover with tasks active that day and assigned people
- Today indicator
