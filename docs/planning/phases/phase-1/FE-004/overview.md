# FE-004 — Task Panel

**Phase:** 1 — Core Data Management
**Track:** Frontend
**Branch:** `feature/FE-004-task-panel`
**Status:** Not started
**Prerequisites:** FE-002

## Goal
Right sidebar showing all scenario tasks grouped by status. Each task card shows key metrics; clicking opens a detail drawer with full info and edit mode.

## Scope
- TaskCard: name, category icon, effort badge, assigned avatars, warning indicator
- Tasks grouped by status: draft / todo / in_progress / review / done
- TaskDetailDrawer: full fields + effort breakdown + dependencies + edit mode
- Add task form
- Warning indicator badge on cards with critical warnings
