# FE-014 — Progress Dashboard

**Phase:** 6 — Progress Tracking
**Track:** Frontend
**Branch:** `feature/FE-014-progress-dashboard`
**Status:** Not started
**Prerequisites:** BE-010, INT-001

## Goal
Execution mode dashboard for daily progress input and project health monitoring. Shows EV metrics, burndown chart, and auto-updating warnings based on actual vs planned progress.

## Scope
- Daily input form: task selector, completion % slider, hours spent, notes
- EV metrics display: SPI, CPI, EAC with color indicators
- Burndown chart: planned vs actual curves
- At-risk indicators on tasks falling behind
