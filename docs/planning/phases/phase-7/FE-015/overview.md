# FE-015 — XP & End-of-Project Review

**Phase:** 7 — XP & Gamification
**Track:** Frontend
**Branch:** `feature/FE-015-xp-review`
**Status:** Not started
**Prerequisites:** BE-011, FE-014

## Goal
End-of-project summary screen showing XP gains, skill level-ups, and contribution highlights per member. Data persists to personnel profiles for future project estimation.

## Scope
- Project summary: total tasks, on-time %, days ahead/behind
- Member XP cards: points gained, level-up animation if applicable
- Skill progress bars showing before → after
- Individual contribution: tasks completed, skills used
