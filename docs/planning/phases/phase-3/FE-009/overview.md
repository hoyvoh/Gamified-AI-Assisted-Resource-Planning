# FE-009 — AI Prompt Interface

**Phase:** 3 — LLM Pipeline
**Track:** Frontend
**Branch:** `feature/FE-009-ai-prompt-interface`
**Status:** Not started
**Prerequisites:** INT-001

## Goal
UI for PM to input project proposal and interact with AI. Includes the project creation flow (proposal input), generated task review, and risk analysis panel.

## Scope
- Project proposal form on /projects/new
- Task generation review: preview generated tasks, accept/edit/reject each
- AI prompt panel (expandable from TopBar): free-form input + quick actions
- Risk analysis results panel
- Loading states for async LLM calls
