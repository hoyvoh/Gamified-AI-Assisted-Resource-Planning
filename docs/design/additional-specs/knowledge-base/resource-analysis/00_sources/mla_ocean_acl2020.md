# Hierarchical Modeling for User Personality Prediction: The Role of Message-Level Attention (ACL 2020)

## Citation

> Lynn, V. E., Balasubramanian, N., & Schwartz, H. A. (2020). Hierarchical Modeling for User Personality Prediction: The Role of Message-Level Attention. *Proceedings of the 58th Annual Meeting of the Association for Computational Linguistics*, 5306–5316. https://doi.org/10.18653/v1/2020.acl-main.472

---

## Problem Statement

Most language-based personality prediction methods assume all documents (posts, messages) generated by a person are equally informative. This assumption is incorrect: some messages carry far stronger signals about personality than others. The paper proposes that modeling **which messages are most informative** — via message-level attention — yields substantially better personality predictions.

> "Not all documents are equally important."

---

## Big Five Personality Traits (OCEAN)

The paper targets all five dimensions of the **Five-Factor Model (FFM)**:

| Trait | Description | High-signal language signals |
|-------|-------------|------------------------------|
| **O** — Openness to Experience | Intellectual curiosity, creativity, preference for novelty | Abstract vocabulary, varied topics, metaphors |
| **C** — Conscientiousness | Self-discipline, reliability, follow-through | Task-oriented language, planning words, precision |
| **E** — Extraversion | Sociability, assertiveness, positive affect | Social words ("friends", "party"), high energy, exclamation marks |
| **A** — Agreeableness | Cooperation, empathy, trust | Positive emotion words, "we" language, reduced criticism |
| **N** — Neuroticism | Emotional instability, anxiety, negative affect | Worry words, negative emotion, self-references |

Scores are **continuous normalized values** (not binary), measuring *degree* of each trait.

---

## Dataset

- **Source:** Facebook status posts from consenting users via a research application (Kosinski et al., 2013)
- **Size:** 68,687 users total
  - Training: 61,746 users
  - Dev set: 4,998 users
  - Test set: 1,943 users (same as Park et al. 2015 baseline)
- **Filter criteria:** ≥ 1,000 words across statuses; age < 65
- **Average per user:** 3,619 words, 165 messages (posted 2009–2011)
- **Demographics:** avg age 23, 63% female
- **Ground truth:** Self-reported Big Five questionnaires (20–100 items); test set used longer 100-item assessment

## Model Architecture

The model is a **hierarchical neural sequence model** with dual attention:

```
Words → [GRU] → Word-level Attention → Message representation
Messages → [GRU] → Message-level Attention → User representation
User representation → [FC layers] → Personality score prediction (per trait)
```

### Step 1 — Word-level Encoding (per message)

Each word `w_j^i` in message `m_i` is fed through a **Gated Recurrent Unit (GRU)**:

```
h_j^i = GRU(w_j^i)                                    (1)
d_j^i = tanh(W_word · h_j^i + b_word)                 (2)
α_j^i = exp(d_j^i ⊤ d_word) / Σ exp(d_k^i ⊤ d_word)  (3)
s_i = Σ α_k^i · h_k^i                                  (4)
```

- `d_word` = learned context vector for word-level attention
- `α_j^i` = normalized attention weight for word `j` in message `i`
- `s_i` = weighted combination of hidden states → message representation

### Step 2 — Message-level Encoding (per user)

Each message representation `s_i` is passed through a **second GRU**:

```
h_i = GRU(s_i)                                         (5)
e_i = tanh(W_message · h_i + b_message)                (6)
β_i = exp(e_i ⊤ e_message) / Σ exp(e_k ⊤ e_message)  (7)
u = Σ β_k · h_k                                        (8)
```

- `e_message` = learned context vector for message-level attention
- `β_i` = normalized attention weight for message `i`
- `u` = user representation = weighted combination across all messages

### Step 3 — Prediction

`u` → fully-connected hidden layers → regression output for each of the 5 personality traits

## Key Results

| Model | Avg Pearson r | vs. Baseline |
|-------|--------------|--------------|
| Word-only attention (baseline) | ~0.30 | — |
| **Word + Message attention (proposed)** | **~0.325** | **+2.5% avg Pearson r** |

- Outperformed all prior state-of-the-art on all 5 traits
- Message-level attention provides the most benefit for **Extraversion** and **Neuroticism**
- High-attention messages reveal trait-specific language patterns:
  - High Extraversion signal: "hangin out", "chillin", social engagement vocabulary
  - Low-signal messages for Extraversion: contain social words but lack clear trait expression

## Limitations

1. **Domain specificity:** Trained on Facebook statuses (2009–2011). May not generalize directly to professional contexts (GitHub, Slack) without domain adaptation
2. **Self-report ground truth:** Personality labels are self-assessed questionnaires, not behavioral/clinical assessment
3. **English-only:** No multilingual validation
4. **Historical data:** Facebook statuses from 2009–2011 may reflect different linguistic patterns than contemporary professional communication
5. **User volume required:** Users needed ≥ 1,000 words; may not apply to low-activity contributors

## Application to Our System

### Core insight to adopt

Not all GitHub comments/PR descriptions/Slack messages are equally informative for personality inference. A **message-level attention mechanism** that learns which messages carry the strongest personality signal is more accurate than averaging across all messages.

### Mapping to developer data sources

| Data source | Maps to "Facebook status posts" | Notes |
|------------|--------------------------------|-------|
| GitHub PR descriptions | Written by author, professional context | Higher signal for Conscientiousness, Openness |
| GitHub review comments | Inter-personal, feedback-giving | Higher signal for Agreeableness, Extraversion |
| GitHub issue comments | Problem-framing, discussion | Higher signal for Openness, Neuroticism |
| GitHub commit messages | Terse, task-oriented | Lower signal but consistency data |
| Slack messages | Informal, social context | Most similar to Facebook statuses |

### Recommended adaptations

1. **Fine-tuning required:** Pre-train or fine-tune on professional developer communication corpora; do not use Facebook-trained weights directly
2. **Message filtering:** Apply attention scores to identify which PR/Slack messages are "high signal" before aggregating to user-level personality scores
3. **Minimum corpus threshold:** Require ≥ 500 words per user (across collected messages) before inferring personality
4. **Ensemble approach:** Combine MLA-OCEAN scores with behavioral signals (activity patterns, response times) for more robust inference

### Ethical constraints

- All message collection must be from repos/workspaces the organization owns or has explicit consent for
- Personality scores are **never shown to the individuals** — visible only to BOD
- Scores must be presented as **probabilistic tendencies**, not deterministic labels

---

## Key Takeaway for System Design

> MLA provides a principled, empirically validated method to infer OCEAN traits from **natural language message corpora**. The hierarchical architecture (word → message → user) is directly applicable to GitHub/Slack data. The key innovation — learning which messages are most informative — is essential for noisy, mixed-signal professional communication environments.
